## 落地结论

选定 **Direction B · MOMENTUM 电光绿亮场**，设计系统如下（用于 `public/styles.css` / `index.html` / `app.js`）：

- 底色 `#F4F6F1`（近白，带一点暖绿倾向）
- 卡片 surface `#FFFFFF`，描边 `#E6E9E0`，圆角 12px
- 强调色（electric green）`#1FBF5F`，深强调 `#16A64E`，强调浅底 `#E6F7EC`
- 文本 `#0F1310`，次要 `#6B7367`，弱化 `#98A193`
- 危险/删除 `#D64545`
- Toast 深绿 `#0F2E1C` / 浅文本 `#E9FCEF`
- 首屏为「今日激励 + 数据」：欢迎语 + 训练日名 + 连胜徽章 + 今日进度条 + 三格数据（本周次数 / 今日组数 / 总容量）

## 数据诚实性约束（实现时遵守）

- 连胜、今日进度、本周次数、总容量全部从真实 `sessions` / `set-logs` 计算，**不编造数字**（方向板里的「42min 耗时」因后端不存时间字段，落地时改为「本周次数」）。
- 训练日名沿用 `schema.sql` 真实名称（上肢A(胸+三头) / 下肢A / 上肢B(背+二头) / 下肢B+手臂），不改「推日/拉日」别名。
